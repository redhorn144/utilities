# Utilities

This is a set of small pieces of code I use for various workflows that did not deserve their own repositories.

Current list:

* WaterMark: places watermarks on images, designed to reduce LLM screenshot cheating during exams.
* torque_plotter: plots torques from nekRS/nek5000 runs. Has utilities to extract them from log files.
* nekAnimation: renders nekRS/nek5000 field files to PNG frames through a saved ParaView scene, for stitching into a movie with ffmpeg.
